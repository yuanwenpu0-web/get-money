## 资产身份实测

对上一轮146个新增现货候选，获取 Gate 完整公开 currencies 元数据，与已保存的 MEXC exchangeInfo 逐币比对。EVM地址忽略大小写，其余地址严格比较，invalid占位地址不参与匹配。

- 139个候选两边都有币种元数据；元数据存在不代表两边都有可交易现货。
- 107个候选在 Gate 链地址列表与 MEXC contractAddress 中出现相同地址。
- 这些是 Gate/MEXC 之间的地址佐证；MEXC exchangeInfo 没有对应链标识，且尚未取得币安永续底层资产的官方链/地址映射，不能判为完整身份验证，更不能直接将351+107算成已验证对冲宇宙。
- KOMA：两边地址一致；MEXC 当前 takerCommission=0.002，即单边0.20%。SIREN：两边地址一致；当前单边0.08%。费用按公开元数据记录，不代表历史或特定账户实际费用。
- BROCCOLIF3B：Gate返回 invalid 地址占位且交易关闭，不能用于匹配；MEXC返回实际地址。此前 Gate 现货盘口不存在的失败响应得到元数据佐证。
- SIREN 的 MEXC firstOpenTime 为1774231500000，处于原历史窗口内部；不能用今天已上市倒推整个窗口一直可交易。该字段含义及迁移历史还需验证，未用于回测筛选。
