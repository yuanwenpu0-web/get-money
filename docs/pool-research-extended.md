# 扩展币池与组合卖出研究

数据：项目配置数据库 `klines` native 1h，上游交易所未逐条核实；UTC 训练 [2025-09-27T00:00:00+00:00, 2026-07-01T00:00:00+00:00)，样本外 [2026-07-01T00:00:00+00:00, 2026-10-26T13:00:00+00:00)。样本外不是未曾观察过的盲测。

训练期数据库有 510 个标的，按交易对和完整小时过滤后 403 个候选；训练期成交额前100为研究币池。完整标的、剔除原因、全部排名、特征和逐币缺失时段见 JSON。

按训练期成交额前50与小时对数收益标准差前50各分高低，交叉为四池；平手按 symbol 排序。波动率不表示市值或行业分类。所有分池依据均在样本外开始前已知，但完整训练期选样会抬高训练期可得性，且实际数据库本身可能带存续偏差。

复用上一轮四个入场信号，两两 AND/OR，配合 RSI50或240小时、48小时、120小时三种卖出，共36候选；每池训练至少每币1.2笔平仓（向上取整），按训练净损益选定，统一池至少120笔。每币200，单边手续费0.04%、滑点0.02%，闲置资金不计收益、不复利。信号收盘确认，下一实际小时开盘成交；缺口后200根禁止新入场，挂单等待，末小时收盘退出；缺末尾按最后价格估值且未计假想卖出成本。买入持有使用相同成本及时间。
