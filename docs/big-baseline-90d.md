# P8 后大基线：90 天窗口 × 5 个 walk-forward（扩大历史复测）

- 日期：2026-10-27
- 目的：P8 native 1h 回填后（457 币 ≥300 天），用更长窗口 + 更多独立测试段复测
  「现货 OHLCV 无方向性 edge」结论是否只是历史宽度不足的假象。

## 设置

- `--window-days 90 --step-days 45 --windows 5 --per-tier 8`（此前受限于 ~90 天深度只能跑 45 天 × 2~3 窗）
- 候选 71 币中 62 币 ≥300 天 1h；窗口回溯最深 270 天，全程覆盖
- 三分支对照（分层 / 统一）+ 反前视分档 + walk-forward，fee=0.0004、slippage=0.0002
- A/B：`--suffix big90`（sentiment ON）vs `--suffix big90nosent`（`--exclude-sentiment`，首次实战）

## 结果（分层组，主指标）

| 窗口 | 终点 | ON 收益 % | OFF 收益 % | ON 夏普 | OFF 夏普 |
|---|---|---:|---:|---:|---:|
| W0 | 2026-10-27 | +0.312 | +0.345 | +3.78 | — |
| W1 | 2026-09-12 | −0.418 | −0.433 | −3.84 | — |
| W2 | 2026-07-29 | −0.479 | −0.479 | −6.98 | — |
| W3 | 2026-06-14 | +0.291 | +0.291 | +2.79 | — |
| W4 | 2026-04-30 | −0.600 | −0.600 | −7.48 | — |
| **均值** | | **−0.179** | **−0.175** | | |

统一组均值 −0.081%（正收益窗口仅 1/5）——分层组不优于统一组。

## 三个结论

1. **历史宽度不是"无 edge"的原因**：训练样本扩大 2 倍（90 天 vs 45 天窗口）、独立测试段
   从 2 个增到 5 个（跨 2026-04~10 不同 regime），分层组均值仍为负且不跑赢统一组。
   P0 释放历史、P8 再释放历史——两次扩大都让结论更稳固而非翻转。
2. **sentiment 退化不是污染源**：W2/W3/W4 两组逐位一致（老窗口 sentiment 本来就全 0）；
   W0/W1 差 ±0.01~0.03pp = 噪声。21 天 sentiment 的边际 PnL 贡献≈0，与 P9 探针边界一致。
3. **夏普逐窗翻转**（+3.78/−3.84/−6.98/+2.79/−7.48）：方向性表现无一致性，
   连"稳定小亏"都算不上——是纯粹的信号缺失，不是成本或过拟合问题。
