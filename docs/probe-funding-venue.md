## 7. 局限与诚实边界

- **全宇宙毛年化不是收益预期，是不可执行的反事实**：它把不可对冲币按「能在第二家所买到现货腿」计入，而那个所的费率、深度、滑点全未知。单所口径的同类反事实（净 +41.8%）已终判不可执行。D3 增量只说明奖金量级值得去问他所数据，不构成任何收益承诺。
- **只报毛超额，不报净收益**：他所现货费率、深度、滑点均未采集，任何净数字都是编造。H3 全局成本 fee_rate=0.0004 / slippage=0.0002 仅作参照记录，未参与计算。
- **幸存者偏差**：币池为采集日在架币种，已下架币费率史缺失，方向上高估收益。
- **现货对可得性是今日快照**：351/507 对照 2026-10-27 的 348/507，差 3 币来自现货上架漂移；历史各期实际可对冲性未落库，无法逐期还原。
- **1000X 前缀换算**：永续 `1000BONKUSDT` 按现货 `BONKUSDT` 记为可对冲；若现货同名不同币会误判，逐币清单已落 JSON 供人工抽查。
- **毛收益不含价格损益**：假设现货腿完全对冲 delta；未计保证金占用、双腿清算风险、出入金与对冲腿再平衡的运营摩擦。
- **结算周期逐币不同**：前瞻费率和按实际 `funding_time` 事件求和（4h 币 18 次/3 天、8h 币 9 次），不假设统一 8h。
- **Gate 1a 通过 ≠ H-F1 成立**：只说明值得去问他所数据；Gate 1b（E1–E6）仍 `BLOCKED`，须用户单独授权采集他所历史 funding 与现货深度。
- **CI 口径**：移动块 bootstrap（block=8 期≈24 天、n_boot=2000、seed=20261112），因为费率强持续、相邻期高度自相关，iid bootstrap 会低估方差。D3 的 CI 对**配对期收益均值**年化后作差，点估计用逐期复利，两者**口径略有差异**；CI 只用于判断增量是否稳健为正。
- **随机基线是随机选币、不是随机方向**：本策略不预测价格方向，H6 的方向翻转基线在此无意义。基线同期同 K 从 trailing>0 的合格币里随机挑，用于分离「排序有用」与「随便拿正费率币就有钱」。
