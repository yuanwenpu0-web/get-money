# 入场价方案研究：信号已定，怎么挂单成交

> 2026-10-30 16:29:37.865000+00:00；16 个主流币，1h × 400 天；信号最小间隔 24 根；限价/突破单等待 6 根；taker 0.040% / maker 0.020%，滑点 0.020%，排队惩罚 0.0bps。

## 口径

- 唯一变量是**入场成交价**。信号时点、止损/止盈**绝对价位**（锚定信号收盘）、同根止损优先、风险预算全部锁死。`*_reanchor` 是唯一例外：止损/止盈跟着成交价平移，风险距离保持与基准一致（实战最常见的写法），单独成组比较。
- 主指标是 **每信号期望 R**：未成交记 0，不删样本、不假设「如果成交了会怎样」。
- `delta` = 方案每信号R − 基准每信号R；`deltaCI` 是**配对**bootstrap 区间，不跨 0 才算真的更好。
- `成交子集delta` = 只在**成交的那些信号**上比，剔除「少交易自然少亏手续费」的干扰，衡量「同样这几笔，挂单是否真买得更好」；带 `*` 表示该子集 CI 显著。
- `逆向差` = 未成交组在基准方案下的 R − 成交组的 R。**为正说明限价单专挑弱的信号成交**。
- `每信号%` = 按**1:1名义仓位**算的价格净收益，只反映价格本身；实盘资金收益以 `每信号R × 风险预算` 为准（本项目风险预算为权益的百分比）。
- 风险距离下限 0.25×ATR：低于此判为不可执行（否则仓位发散，回测会虚增收益）。
- `hold_24` 是隔离口径：**仓位固定**（1R = 1×ATR，与成交价无关）、出场时点锁定在信号 bar + 24。这里任何差异都不可能来自仓位变化。

## 结论（自动从上面的数据算出）

- 基准（下一根开盘市价）每信号 **-0.1159R**，平均风险距离 1.5378%；信号本身没有正 edge，所以下面所有方案也都是负的——**入场价优化只能减少亏损，不可能把负期望变成正期望**。
- 推荐门槛：配对 CI 显著 + 分段 ≥3/4 同号 + **成交率 ≥50%**（成交率太低的方案只是「偶尔做一笔」，实盘样本会稀到无法验证）。
- 按**价格口径**（1:1名义仓位、不含仓位缩放）最优的是 `limit_a04_w1_reanchor`：每信号 -0.0360%（基准 -0.2206%），风险距离 1.5248%（基准 1.5378%）。
- **两种止损写法结果不同，机制也不同**：
  - 止损留在信号收盘下方（`limit_a04_w1`）：买低 0.4ATR 后风险距离从 1.5378% 缩到 1.1182%，仓位被动放大，`每信号R` -0.0270 里有一部分是杠杆效应，不是价格优势。
  - 止损跟着成交价下移（`limit_a04_w1_reanchor`）：风险距离维持 1.5248%，仓位不变，`每信号R` -0.0176 才是纯粹的价格改善。
  - 两者在 `hold_24`（仓位完全固定）里结果完全相同，正好证明上面的差异只来自仓位。
- 稳健最优：**`limit_a04_w1_reanchor`**（买在下方 = 回撤挂单），每信号 -0.0176R （改善 +0.0983R，CI [0.0442, 0.1532]，分段 4/4 同号，13/16 币更好）。成交率 58.4%，成交价 +40.6bps。
- **临界判据**：这套挂单在「信号自身毛 edge < +0.422R（≈ 0.65% 价格）时占优」，超过就该直接市价。本研究的信号 edge 为 -0.1159R，低于临界值，所以挂单更优这个结论是可信的；换成真有 0.5R+ edge 的信号，结论会反过来。
- **逆向选择是真的、而且很大**（以 `limit_a04_w1` 为例）：没成交的那批信号在基准下平均 +0.1857R，成交的那批只有 -0.3308R，相差 +0.5165R。也就是说挂单便宜了 40.62bps，但**挑中的恰恰是最弱的信号**；净改善是这个折扣硬扛过逆向选择之后剩下的部分。任何「挂单更便宜所以更好」的直觉都必须先过这一关。
- **挂太深会自毁**：`limit_atr_1.0` 成交价能改善 99.21bps，但成交率只剩 52.4%，止损率升到 88.8%，每信号只剩 -0.1087R。深度有最优值，不是越便宜越好。

## 读法

- **每信号R 才是可决策的数字**。成交率 30% 但每笔 R 翻倍的方案，只有 0.3×每笔R > 基准R 时才真的更好。
- **逆向差为正就要警惕**：没成交的那批信号本来更赚钱，限价挂单等于系统性地错过好机会。
- **止损率上升是必然代价**：买得更低 → 离结构性失效位更近 → 同样止损位被触及更频繁；赢时因仓位更大而赢得更多。平均风险% 同步下降即为证据。

## 限制

1. 只有多头。空头是精确镜像（卖单挂收盘上方），结论可直接平移。
2. 同根止损/止盈冲突一律判止损先成交；对所有方案一致，但整体偏低。
3. 未建模最小跳动、部分成交、下单延迟与手续费阶梯；maker 假定必然成交且无排队损失（实盘中挂单队列靠后可能完全不成交）。
4. 池化样本存在重叠持仓；bootstrap 按信号重采样仍偏乐观，结论只用于**方案排序**，不用于宣称绝对收益。
