## 3. 口径与参数

- **因子**：`oi_value_usd` 原值、`oi_value_z7d`（168 根 rolling z-score，`min_periods=72` 近似 7 天）、`oi_change_24h`、三个比值因子。采集端外对齐的 0 值按 `attach_sentiment` 同样规则转 NaN。
- **标签**：`close[t+24]/close[t]-1`，要求 t..t+24 的 25 根 bar 全部存在（反向 rolling 判定），否则该格置 NaN；横截面 demean = 减去该时点全市场中位收益。
- **因果**：因子只用 t 时刻及之前数据，标签只用 t 之后；未收盘 bar 不参与；固定种子 `20261111`。
- **统计**：逐期 Spearman rank IC（rankdata 处理并列）；95% CI 用 **24 期移动块 bootstrap**（n_boot=2000），因为相邻时点 IC 强自相关，iid 重采样会低估方差；负对照用 200 次逐期独立置换。
- **样本外切分**：本轮为探针，按时间中位数做前／后半窗一致性检查，**无训练／验证／测试三段切分、无选参**。
- **撮合**：无。`trades=0`，无成交笔数门槛、无池化 CI、无多种子随机方向基线（随机基线在本轮不适用；负对照为逐期置换零分布）。
- **量具自校准**：正对照（因子＝标签）IC **1.0**、501 期、std 0；负对照 200 次置换零分布均值 **−0.00004**、5%/95% 分位 ±0.0038。量具形状正常。

### 4.1 主判据

| 指标 | 读数 | H1 门槛 | 判定 |
|---|---:|---|---|
| 逐期横截面 IC 均值 | **−0.01597** | \|IC\|>0.02 | **未过** |
| 95% 置信区间（block24） | **[−0.03972, +0.00971]** | 不跨 0 | **未过（跨 0）** |
| 中位数 / 标准差 | −0.0210 / 0.0744 | — | 波动远大于均值 |
| 同号期占比 | 60.42% | ≥60% | 勉强过 |
| 逐币时序 IC 同号币占比 | 65.76%（514 币，均值 −0.08173） | ≥60% | 过 |
| 置换经验 p（双侧） | 0.000（分位 0.00） | <0.05 | 过 |

| **gate 合计** | **3 过 2 不过** | 五关全过 | **FAIL** |

`permutation p=0` 与 `CI 跨 0` 看似矛盾，实为量具设定差异：置换零分布假设各期独立（零分布极窄 ±0.0038），而 block bootstrap 保留了自相关、方差更大。**按 H4 的保守原则，以保留自相关的 CI 为准**。

### 4.2 机制归因：信号在「时间维度」，不在「券维度」

| 口径 | 读数 |
|---|---|
| P9 原口径（逐币时序，triple-barrier 标签） | IC −0.0746，84% 币同号负 |
| 本轮逐币时序（固定 H=24、demean 标签） | 均值 **−0.08173**，中位 −0.08911，65.76% 同号负（514 币） |
| 本轮逐期横截面（主判据） | 均值 **−0.01597**，CI 跨 0 |
| **全市场平均 OI z vs 全市场未来 24h 收益**（时序 Spearman，430 期） | **−0.23249** |
| OI z 的平均横截面 std / 平均 \|横截面均值\| | 1.15547 / 0.5893 |

**一个必须点破的方法学事实**：raw 标签与 demean 标签的 IC 完全相同（都是 −0.01597）。这不是 bug —— Spearman rank IC 对「每期标签减去一个常数」是恒等变换。它恰恰说明**横截面 IC 本身已经天然剔除了市场共同平移**，所以逐币时序与横截面读数的落差不是「标签没去 beta」，而是**聚合维度不同**：前者测「同一个币在不同时间 OI 高时是否跑输」，后者测「同一时间高 OI 币是否跑输低 OI 币」。

结合 −0.23249 的共同因子相关，最自洽的解释是：**OI 主要携带全市场杠杆周期的共同择时信息，而非跨币选币能力**。逐币时序 IC 把这段共同时间模式在 514 个币上重复平均，读起来很强；一旦改成同一时点跨币排序，共同成分被对消，只剩 −0.016 的弱信号，低于 0.02 实用门槛且不确定。

注意 −0.23249 是两条平滑且标签窗口重叠的时序序列之间的相关，**尚未做非重叠样本、样本外、成本与随机基线检验，不能当作可交易择时 edge**，只作机制归因的探索性读数。

### 4.3 探索性组合与多重比较（H7）

17 个组合（6 因子 × 3 H 减去主判据）做了 block bootstrap CI、100 次置换经验 p 与 BH-FDR。其中 3 个 CI 不跨 0：

| 因子 | H | 均值 IC | 95% CI | q |
|---|---:|---:|---|---:|
| oi_value_z7d | 8 | −0.02263 | [−0.03904, −0.00340] | 0.000 |
| taker_buy_sell | 24 | −0.00591 | [−0.01126, −0.00041] | 0.000 |
| taker_buy_sell | 48 | −0.00586 | [−0.01184, −0.00018] | 0.000 |

17 个里 **15 个 q<0.10**。这个「遍地显著」本身就是警报：置换零分布未保留跨期自相关，经验 p 被系统性压小，FDR 在该设定下失去意义。更关键的是 **`oi_value_z7d` 在 H=8 为 −0.023、H=24 为 −0.016、H=48 翻成 +0.013**，符号随前瞻跨度翻转；同号期占比在 `oi_value_usd` 上只有 48–54%。按 H7，这批读数一律**只作观察，不得事后挑选取参或投产**。

## 5. 判定

- **verdict**：**`inconclusive`**（探针级）。主判据 95% CI 跨 0，按词表只能写「不知道」，**不等于已证无效、也不等于小幅为正**。
- **gate**：H1 **FAIL**，因此**不授权投入实现、不授权受控 A/B、不进任何绑定**，`default_enabled=False`。
- **池化 CI / 随机基线**：本轮 `trades=0`，无每笔期望 CI、无多种子随机方向基线；不构成 H4 的净收益 edge 判定，也不满足 `MIN_POOLED_TRADES=30`。
- **与历史结论对照**：与 P9「84% 币同号负」方向一致、量级可比（本轮逐币 −0.0817 / 65.8%），**未推翻 P9 的时序读数**；但把 P9 的适用边界从「跨币 alpha」收窄为「共同时间成分」。与 P6（funding 线性特征 +0.0246 / 58% 同号判证伪）、P4（换频率无效）无冲突。
- **对 P9 roadmap 的影响**：原计划「攒满 60 天后跑 OI 特征 ON/OFF 的受控 A/B」**仍可做，但假设要改写**。若信号是市场级共同择时，逐币特征 ON/OFF 的比较容易被 beta 掩盖；更对口的实验是市场级仓位开关，并强制非重叠样本、样本外切分、扣 0.12% 成本与多种子随机基线。在数据链修好之前，两种 A/B 都做不了。

## 6. 局限

- sentiment 仅 21.83 天且停在 2026-10-28；native 1h 停在 11-04；**单一样本期、BTC −5.691% 的下跌市**，跨市场状态稳健性无法验证。
- `oi_value_z7d` 用 168 根 rolling、`min_periods=72` 近似 7 天 z-score，与 P9 完整 7 天口径存在预热期偏离；98 期因此被剔除。
- 标签为固定 H 的 close-to-close 收益，**不是** P9 的 triple-barrier 止盈标签；逐币 IC 数值不得与 P9 直接相减。
- IC 是毛价格关联，**未扣 0.12% 双边成本**、资金费率、盘口深度、滑点、强平、部分成交；名义本金口径，不得与 margin 口径报告相减。
- 置换零分布按各期独立打乱、未保留自相关；与 block bootstrap CI 冲突时以后者为准。**FDR 在该零分布下不可靠**，不应据 q 值下结论。
- 横截面 IC 只测券维度排序，**不能排除 OI 在时间维度上存在择时价值**；−0.23249 未做非重叠／样本外检验。
- 探索性组合未参与 gate，不得事后挑选；未模拟任何撮合，也不含成交笔数门槛与池化 CI。

## 7. 结论与后续

**一句话结论**：P9 的 OI 负向 IC 在本轮以固定 H 标签复现为逐币 −0.0817 / 65.8% 同号，但一旦改成同一时点跨币排序只剩 −0.01597、95% CI [−0.0397, +0.0097] 跨 0，H1 未过 —— 它更像全市场杠杆周期的共同择时成分，而不是可交易的选币 alpha。

- **是否启用**：**不启用**。`default_enabled=False`，不进绑定。本轮未改任何 spec、绑定、生产参数或前端，只新增两个离线只读脚本与报告。
- **是否进入下一阶段**：**否**。按 H1 与 H2，不换周期、不调阈值、不用 H=8 的探索性读数来救它。
- **当前最紧迫的不是找新因子，而是修数据链**（见 §2）。三条符合 H2 的后续假设：

| 假设 | 可证伪判据 | 数据前置 | 状态 |
|---|---|---|---|
| **H-A 市场级杠杆择时** | 非重叠样本的样本外净收益 CI 下界 > 0 且跑赢多种子随机基线，否则终止 | 恢复 sentiment 采集、补回 10-28 后缺口、累积 ≥60 天 | `BLOCKED_BY_DATA` |
| **H-B 逐笔成交顺序** | 逐笔方向游程／大单簇的 IC 探针 \|IC\|>0.02 且同号币≥60%，否则终止 | 新建 aggTrades 采集（`data.binance.vision` 日归档可回填）；**不得退回 K 线级 taker 汇总** | `BLOCKED_BY_NEW_SOURCE` |
| **H-C 盘口挂撤单 / 多所现货腿** | 挂撤单失衡或跨所价差先过 IC 探针，否则终止 | 盘口快照只能从现在开始录；多所需接 Gate/MEXC | `BLOCKED_BY_NEW_SOURCE` |
