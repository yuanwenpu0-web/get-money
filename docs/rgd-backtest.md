## 口径与数据限制（必须先读）

1. **撮合口径**：完全复刻 Pine 默认订单语义——信号收盘下市价单、次根开盘成交；信号 bar 成交当根无止损（入场 bar 裸奔）；TP1 限价部分平 50%；保本止损滞后一根生效；接受度加权 trailing 逐根 ratchet 不回退；不强制收盘平仓（末根未平仓按盯市计入净值）。
2. **HTF 因果**：15m 帧只看到「上一根已完成」的 4h bar（`searchsorted` 于 `t - 4h`），同一 4h 桶内 16 根 15m 的 hh/ll 完全相同，未完成桶已剔除。
3. **跨缺口**：K 线缺口把序列切成多段，各段独立撮合、账户权益按段复利结转。
4. **最短段长**：单段不足 800 根的片段直接丢弃（指标预热需要 600 根）。
5. **样本口径**：每个币种是独立的 10,000 账户；全市场数字是截面统计，不等于一个组合账户的收益。15m 历史只覆盖部分币种，`universe.skipped` 已列明被跳过的币，**零成交不能读成没有信号**。
