# 结论：换 15m 不会更赚；趋势反转式分批止盈在现有策略上是负贡献

被问的问题：**现在开着的策略换成 15m K 线会不会盈利更好？顺便把「趋势反转（supertrend_current）」
那套 1R/2R/3R 分批止盈搬过来。**

两份实测报告（本文件只做汇总，数字以它们为准）：

- `docs/interval-exit-study.md` / `.json` — 通用策略（趋势反转 / 吸收反转 / Fusion Scalp）的 15m vs 1h
  与四档止盈结构，40 币 × 300 天，测试段墙钟对齐（最后 75 天）。
- `docs/research-interval-exit-study.md` / `.json` — 现在真正在跑的两个研究池策略
  （1h 持有型）换 15m 与加止损/分批止盈，90 天窗口、同币配对。

---

## 1. 「现在开着的策略」是哪些

`strategy_configs.enabled=1` 有 7 个，但**真正有生效绑定的只有两个研究策略**：

| 策略 | 周期 | 池 | 状态 |
| --- | --- | --- | --- |
| `research_high_turnover_high_vol` | 1h | 高成交额高波动（25 币） | 在跑 |
| `research_low_turnover_high_vol` | 1h | 低成交额高波动（25 币） | 在跑 |
| `supertrend_current` | 15m | all | 策略开着、**绑定 enabled=0**（昨天还在跑，51 笔模拟单） |
| `absorption_reversal` / `capital41_fusion_scalp` / `rgd_donchian_v2` / `simple_zigzag_double` | — | 无生效绑定 | 只有开关是开的，不进巡检 |

所以「换 15m」这件事要分两族看：**研究池策略（1h 持有型）** 和 **趋势反转（本来就是 15m）**。

## 2. 趋势反转换周期：1h 明显好于 15m

同窗口（300 天，测试段最后 75 天）、同参数、同撮合，40 币池化：

| 出场结构 | 15m 每笔 | 1h 每笔 |
| --- | ---: | ---: |
| 单档 3R | **-0.299%**（CI -0.382~-0.209，negative，7459 笔） | -0.016%（CI 跨 0，1611 笔） |
| 分批 1/6·1/3·1/2 @1R/2R/3R | -0.313%（negative） | -0.058%（跨 0） |
| 分批等分 1/3 | -0.318%（negative） | -0.084%（跨 0） |
| 1R 先平一半 | -0.322%（negative） | -0.105%（跨 0） |

- **同币配对差中位数 -10.9pp，只有 20% 的币 15m 更好**：不是几个币拖累，是普遍更差。
- 机制很清楚：15m 成交笔数是 1h 的 **4.6 倍**（7459 vs 1611），每笔往返成本 0.12%，
  换手放大直接把本来就很薄的 edge 吃穿。BTC/ETH 同窗口：15m -14.2% / -9.4%，1h -4.2% / -1.7%。

## 3. 分批止盈：两族策略上都让结果变差

**趋势反转本身**（同一周期内比较，行内从左到右）：

- 15m：单档 -0.299% → 分批 -0.313% → 等分 -0.318% → 1R 平一半 -0.322%，**越早落袋越差**。
- 1h：-0.016% → -0.058% → -0.084% → -0.105%，同样单调变差。

原因：这套策略的 R 只有 1.5×ATR，1R/2R 很浅，分批等于把仓位在趋势还没走出来时陆续交出去，
剩下的 1/2 仓位继续吃原来的止损；而分批本身多付两次手续费。

**两个研究池策略**（90 天、同币、每笔固定 200 名义）：

| 出场结构 | 高成交额 15m | 高成交额 1h | 低成交额 15m | 低成交额 1h |
| --- | ---: | ---: | ---: | ---: |
| 现状（定时出场，无止损无止盈） | **9.70%** | **9.87%** | 0.57% | 0.82% |
| 加 1.5×ATR 止损 | 0.68% | 3.98% | 0.29% | -0.14% |
| 再加 1R/2R/3R 分批止盈 | 0.09% | 0.98% | -0.02% | -0.36% |

- **加止损就掉 90%**（15m 上 91% 的单被打掉），再分批直接归零。
- 原因是这两个策略的 edge 来自**扛住波动持有 5 天 / 2 天**；1.5×ATR 在 15m 上只有零点几个百分点，
  等于把趋势单改造成噪声交易。分批止盈同理：先落袋的那部分永远拿不到后面的大段。

## 4. 15m 还有一个硬约束：数据不够

研究池 50 个币里，**native 15m 有 30 个只从 2026-10-15 起**（约 1000 根），1m 补齐也只到 2026-07-28。
90 天窗口下 15m 只剩 **13/25** 与 **8/25** 个币可用，窗口再拉长还会继续掉。
换句话说，就算结论支持 15m，现在也没有足够历史去验证、更没法做样本外。

## 5. 处置

1. **不换 15m。** 两个方向都不支持：有 edge 的那族（研究池 1h）换 15m 后与 1h 打平
   （9.70% vs 9.87%，配对中位差 +44pp 但 CI [-2.5, +79.5] 跨 0，且只有半数币有数据）；
   趋势反转那族换 1h 才明显更好。
2. **不加分批止盈。** 趋势反转式 1R/2R/3R 在两族策略上都让每笔更差，且方向一致、无例外。
3. **能力保留但默认关**：`absorption_reversal` 已接上同一套分批止盈参数
   （`tp1_r/tp2_r/tp1_fraction/tp2_fraction/tp3_fraction`，默认 `0/0/1` = 与改动前完全等价，
   只在真的激活 ≥2 档时才走分批路径，成交状态标签不变）。想试别的策略可以直接在绑定上覆盖，
   不需要再改撮合。
4. 下一步值得做的不是换周期，而是**先把 15m/1m 历史补齐**——它同时是吸收反转复检、
   15m 验证、以及 intrabar 类特征的前置条件。

## 7. 不能忽略的偏差

- 研究池成员是按「最近 168 小时」成交额/波动率筛出来的，却用来回放更早的行情 → **事后选币**。
  所以研究池那几行的绝对收益（9.7%、9.87%）是**上界，不是预期**；能用的只有同币配对差值。
- 15m 上 `max_hold_bars` / `cooldown_bars` 按 bar 计，换周期后墙钟时长自动缩短 4 倍；
  本轮沿用原参数，读数里混着这一层效应（对趋势反转不利，因为它的时间止损更早触发）。
- 未计资金费率、盘口冲击；`minimum_sample_trades` 门槛（<30 笔判 insufficient）已生效，
  `absorption_reversal`（17/3 笔）与 `capital41_fusion_scalp`（71/13 笔）的读数因此不可用。
