# Simple ZigZag Double —— 主流币 × 近一年回测汇总

- **策略**：`simple_zigzag_double`（Pine 原脚本口径，专用止损单撮合器，
  见 `simple-zigzag-double.md`）
- **样本**：`MAJOR_SYMBOLS` 全部 16 币（BTC/ETH/SOL/BNB/XRP/DOGE/ADA/LINK/AVAX/
  LTC/DOT/SUI/TRX/NEAR/APT/BCH）
- **周期**：1h（主）与 4h（对照）；**区间**：近 365 天（各自数据起点见 JSON 的
  `start` 字段，1h 深度约 400 天）
- **成本**：与 Pine 一致 —— commission 0.1%/边、无滑点；初始权益 1,000,000
- **结论先行**：近一年 16 个主流币**无一正收益**（1h），4h 也仅 3/16 为正。
  这不是集成或撮合问题——**该脚本在 1h/4h 级别不存在正 edge**，
  与项目 P0–P10「现货 OHLCV 价格预测全线证伪」的结论一致。
  数据：同名 `simple-zigzag-majors-1y.json`。

## 3. 结论与判读

1. **频率越高死得越快，但换频率救不回来**：1h 等权 -51.4% → 4h -28.2%
   （换手 254→63 笔，成本近似降 4 倍），亏损主要来自信号本身而非成本——
   即便 4h 免成本，多数币仍为负。
2. **最伤人的是 NEAR 型反例**：买入持有 +101.9%，策略 -79.0%。止损反手机制在
   大趋势币上反复逆势止损，**趋势捕获为深度负贡献**，说明"通道突破 + 反手"
   结构在这段行情里系统性站错边。
3. **4h 的三个正收益币（SUI +58.4%、BCH +60.5%、BNB +2.2%）不可当 edge**：
   16 币 3 个正收益，符合噪声比例；PF 分布连续（0.32~1.37）无聚集结构，
   无参数或机制层面的解释力。
4. **与既有结论一致**：本项目 P0–P10 已证伪 1h OHLCV 路线的全部信号方向
   （|IC|<0.05）。本次结果是把 Pine 反手止损结构跑在同一数据上的又一次确认。
   **不建议启用该策略的模拟盘绑定；不建议投入参数寻优。**

## 4. 复现

```
.\.venv\Scripts\python.exe backend/scripts/zigzag_backtest.py --symbol BTCUSDT --interval 1h --days 365

```
