# Simple ZigZag Double —— 主流币参数寻优报告

- **样本**：`MAJOR_SYMBOLS` 16 币 + ETCUSDT，共 17 币；区间近 365 天
- **网格**：通道长度 {3,5,8,13,21,34} × 检测灵敏度 {2,3,5} × 方向 {双向/仅多/仅空} = 54 组合/币
- **协议**：时间 66/34 切分（训练 ~240 天 / 样本外 ~125 天），
  **选参只看训练段币间中位收益**，样本外仅作验证——避免全样本挑最优的过拟合
- **成本**：0.1%/边、无滑点、初始 100 万；撮合为 Pine 止损单专用 broker
- **数据**：`simple-zigzag-opt-majors.json`（1h）、`simple-zigzag-opt-majors-4h.json`（4h）
- **寻优入口**：`backend/scripts/zigzag_optimize.py`（可复现，ProcessPool 并行）

## 1. 结论先行

> **存在一个双段（训练+样本外）同时为正的最优组合：`4h + L21/D5 + 双向`。**
> 1h 上**不存在**这样的组合；做空单边家族的「训练段高分」全部是熊市行情的行情红利，样本外崩塌。

| 维度 | 1h | 4h |
|---|---|---|
| 训练+样本外中位同时为正的组合数 | **0 / 54** | **2 / 54** |
| 训练/样本外中位收益相关系数 | -0.319（负相关=选参无效） | 见 §3 邻域 |

## 2. 为什么 1h 没有最优参数

- 池化训练段 Top5 全部是 `short_only` 家族（train_med +16.6% ~ +1.3%），
  样本外中位 **-12% ~ -23%，0~2/17 为正**——训练段（BTC -45%、ETH -59%）是熊市，
  做空随便赢；样本外（BTC +33%、NEAR +137%）是牛市，同一批参数全线亏损。
- 全网格 54 组合的训练/样本外相关系数 **-0.319**：样本内排名对样本外**没有预测力**，
  1h 上调参就是拟合行情方向，不是拟合策略。
- 每币 best-of-54 相比默认参数中位改善 +83 个百分点（NEAR -79.6% → +189.7%），
  这就是数据窥探的幅度，不可采信。

## 4. 判读与边界（必读）

1. **这不是「变出 alpha」，而是「少亏」的结构信号**：慢通道（L≥13）把换手从
   1h 的 ~255 笔/年压到 ~30 笔/年，手续费占比从 32% 降到 ~2-3%；
   4h 双向保留了两个方向，熊市吃空单、牛市吃多单，对行情方向的依赖显著低于 1h。
2. **回撤不可接受**：中位 -39%、尾部 -89%。100% 权益全仓进出是 Pine 原脚本口径
   （`default_qty_value=100`）；实盘必须把 `lot_long/lot_short` 压到 10-20% 量级，
   收益同比缩水但回撤才可控。
3. **ETC 在诚实选参下依然无解**：即便最优组合下全样本 -38%（全部 54 组合中
   只在数据窥探下短暂为正）。ETC 不建议绑定该策略。
4. **样本外只有 ~125 天牛市**：候选的样本外表现部分来自行情，正负率 10/17
   是可接受但非压倒性的证据。建议先做 60 天模拟盘前向跟踪再评估，不直接实盘。
5. 与项目主线结论一致：1h OHLCV 路线已被 P0–P10 证伪；本次唯一新信息是
   **「4h 慢通道双向」这条低换手路径值得观察**，而非高频路线翻案。

## 5. 若要落地（绑定层参数）

系统绑定支持策略×池参数覆盖。若决定跟踪，建议配置：

```json
{"interval": "4h", "params": {
  "long_length": 21, "short_length": 21,
  "long_detection": 5, "short_detection": 5,
  "lot_long": 15, "lot_short": 15
}}
```

绑定币种池建议剔除 ETC/AVAX/DOT/TRX（四个诚实口径下最差的币）。

.\.venv\Scripts\python.exe backend/scripts/zigzag_optimize.py --interval 4h --days 365
