# Capital41 Fusion Scalp 全可用币分池样本外实验

数据：项目配置数据库 `klines` 原生 1h，上游交易所未逐条核实。UTC 训练 [2025-09-27T00:00:00+00:00, 2026-07-01T00:00:00+00:00)；测试 [2026-07-01T00:00:00+00:00, 2026-10-26T13:00:00+00:00)。数据库候选 405 个，训练期连续且合格 405 个；完整币种、逐币结果、参数和质量记录见配套 JSON。

币池仅按训练期全周期完整的 USDT 币选取，排除 USDC、FDUSD、TUSD、USDP、DAI、EUR、GBP、PAXG 对 USDT 的交易对，以及名称后缀 UP、DOWN、BULL、BEAR 的杠杆币；BTC、ETH 包含在内。按训练期总成交额降序均分三池，平手按名称排序。该范围是数据库中满足训练覆盖的全部币，并非交易所全部历史上市币；固定全训练期连续会造成选样和存续偏差。

复用项目原指标，多空均做。其 EMA、RSI、Williams %R、ATR 与成交量条件均须同时满足；原指标无退出规则。候选为 require_turn 真/假、ATR 扩张倍数 1.0/1.1、固定持有 24/72 小时共 8 组，其他指标参数用原默认值。每池训练期至少 30 笔平仓，按训练净损益最大选择，平手按候选次序；未分池统一参数至少 90 笔。候选未满足交易数时不选择。

K线收盘信号在下一根实际K线开盘成交；每币单仓、双向、每笔固定名义200，池资本=币数×200，闲置资金不计收益，不复利。单边手续费0.04%、滑点0.02%，均已计入损益；费用另列，仅含手续费，滑点体现在成交价。持有期按实际时钟，缺口中挂单等待下一根实际开盘，缺口后200根不新开仓。预定区间末小时收盘强平；末尾缺失则按最后收盘盯市且未计假想退出成本。未计资金费、借币费、冲击、保证金限制。

分池合计测试收益 1.415%，平仓 271 笔；统一参数 {'require_turn': True, 'atr_expansion_multiplier': 1.1, 'hold': 24} 的测试收益 1.200%，平仓 259 笔。两者使用相同币池和固定资本。

测试期每币应有 2821 根，完整覆盖 46/405 币，实际 1096976/1142505 币小时。

局限：样本外区间此前在项目其他研究中已被观察，不是项目层面的盲测；仅一次切分和8组候选，参数搜索仍有过拟合风险。缺口会影响信号、挂单和持仓估值，滞后末价不代表可成交；指标在缺口后重热身200根但不重置历史。未核对历史上架、退市及可交易性，未计资金费和市场冲击；结果不是可直接复现的永续账户收益。未计算逐时权益回撤、统计显著性或多重检验校正。训练期选币会使训练收益带选样偏差。研究退出机制与正在开发的 ATR 止损止盈 spec 不同，不能等同其绩效。
