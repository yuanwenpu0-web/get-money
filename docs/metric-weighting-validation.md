## 0. 参数、口径与数据覆盖现实

- 币种集（Top10 固定）：BTCUSDT、ETHUSDT、SOLUSDT、XRPUSDT、NEARUSDT、DOGEUSDT、JCTUSDT、ORDERUSDT、IRYSUSDT、APRUSDT
- 策略：trend_follow + mean_reversion；费率 fee=0.0002、slippage=0.0002（双边 maker）
- 主实验：7 个窗口 × 200 天，步长 30 天；再平衡每 24 根 1h K 线（约每日）

## 5. 加权公式说明

仓位权重（weight_mode=metric，每 rebalance_bars 根 K 线重算，指标经 metrics_as_of 反前视取数）：
```
score_i = 0.5*tanh(sentiment_divergence_i)      # 聪明钱相对散户更偏多 → 加分
        - 0.3*min(|crowd_ls_z_i|, 3)/3           # 散户拥挤度极端 → 减分（拥挤=反向风险）
        + 0.2*rank_score(market_cap_rank_i)      # 市值靠前 → 加分（流动性/容量）
rank_score: 第1名=1.0，线性衰减到第51名=0；排名未知=0.5（中性）
score → softmax(T=0.5) → 非负 → 归一 sum=1 → 单币上限 clamp 到 2/n；任一币种指标缺失 → 整体退回等权
```
regime 策略权重（regime_weighting=True，同币种 trend_follow vs mean_reversion）：
```
w_trend = clamp(0.5 + A*(fng_value-50)/50 - B*min(|crowd_ls_z|,3)/3, 0.2, 0.8),  A=0.25, B=0.15
w_mean_reversion = 1 - w_trend
```

## 6. 前视声明

- **市值排名存在轻微前视**：CoinGecko 无免费历史，回填时把当前市值排名作为常量注入所有历史行。因此 rank_score 项（占 score 权重 0.2）带有前视信息，结论需打折。
- 其余指标（多空比/大户比/主动买卖比/未平仓量/FNG）均为 ts <= 决策时刻的历史值，经 metrics_as_of 前向填充读取；z-score 因果构造：回填时每条只用它之前的已算特征作历史，不掺入未来。

## 8. 结论

**未改善，不建议启用。** 理由：
1. 指标覆盖硬约束：免费源仅约 30 天，7 个 200 天窗口中 5 个覆盖为 0（完全无指标），另 2 个仅覆盖 0.2% 与 15.2%；
2. 在唯一真正有指标信号生效的窗口组（覆盖>0，n=2）上，相对 baseline：B -0.07%、C -0.04%——均为负，即指标加权在有数据的地方是减分的；
3. 覆盖=0 的 5 个窗口差异约 0.00%，属定期再平衡的机制差异，非指标效应；
4. 门禁（正窗口数增加 且 均值更高）两配置均未达成：正窗口数同为 3/7，均值均更低。
因此保持 `metrics_assist_enabled` 默认 False，指标层继续作为观测能力保留；覆盖期内短窗口补充实验因无样本外测试段全部返回空，亦未产生可用结果。若要真正验证加权价值，需先解决历史深度（付费数据或自行累积 6 个月以上快照）。
