## 0. 怎么读这张表

五个预测目标分开看，因为用途完全不同：

| 列 | 预测什么 | 用在哪 |
| --- | --- | --- |
| `收益IC` | 样本外每笔净收益中位数 | 选币、选策略族 |
| `夏普IC` | 每笔收益 ÷ 风险（mean÷std） | 单位风险回报，选币首选口径 |
| `风险IC` | 样本外每笔收益的离散度（std） | 仓位大小、风险预算 |
| `尾部IC` | 样本外最差 5% 单笔亏损 | 止损距离、爆仓风险 |
| `回撤IC` | 已实现权益最大回撤 | 单币风险预算上限 |

三种相关口径，**层层剥离混杂**：

| 前缀 | 含义 | 为什么需要 |
| --- | --- | --- |
| `ic` | 原始 Spearman | 基线，混入了所有共同因素 |
| `pic` | 控制 log 流动性 | 不控的话所有维度都退化成「低流动性币波动大」 |
| `picv` | 同时控 log 流动性 + `vol_hourly_std` | **判定用这个**：剥离波动率后仍有信息才算真发现 |

`picv` 是核心。波动率类指标预测「收益离散度」的原始偏 IC 能到 0.5，但那是**定义式恒等**（波动率预测波动率），不是发现。第 5 节单独列出了这批伪发现。

| 判定 | 门槛（全部用 `picv`） |
| --- | --- |
| 可用·收益 | `\|picv 收益\| ≥ 0.10` 且 符号一致率 ≥ 0.80 且 收益超随机率 ≥ 0.67 |
| 可用·风险 | `\|picv 风险/尾部\| ≥ 0.10` 且 符号一致率 ≥ 0.80 且 风险超随机率 ≥ 0.67 |
| 参考 | `max(\|picv\|) ≥ 0.08` |
| 无用 | 其余 |
