# P3 探针报告：特征扩展能否出 alpha（结论：不能）

> 路线图 P3 计划"特征扩展：量价结构 + 横截面强弱"。本探针在投入架构改动（横截面 pooled）
> 之前，先用最低成本验证**候选特征是否对「止盈」标签有任何预测力**。判定标准：IC（点二列相关）> 0.02 才值得正式接入。

## 1. 探针设计

- 取 40 个 1h 历史 ≥120 天的币，对齐到 2869 根共同时间索引（400 天窗口）。
- 目标 = 该币 triple-barrier +1（止盈）标签（与 P2 一致，对齐实盘出场）。
- 三类候选特征，逐币算 IC 后取均值：
  1. **时序动量**：单币 20 根收益率（`ret_20`）——代表现有单币时序信息。
  2. **横截面排名**：同 t 所有币 `ret_20` 的 z-score——代表路线图 P3/P4 的"横截面强弱"。
  3. **量价背离**：OBV 累积 20 根斜率、close 与 volume 的 20 根滚动相关——代表"量价结构"。

## 2. 结果（400 天 / 1h）

| 特征候选 | IC 均值 | 判定 |
|---|---:|---|
| 时序动量（20根） | +0.020 | 微弱，贴随机 |
| 横截面排名 z | +0.004 | 无增量 |
| OBV 斜率 | −0.016 | 负向，无意义 |
| 量价相关 | +0.003 | 无增量 |

SOLUSDT 单币明细：ic_ts=0.062 / ic_xs=0.006 / ic_obv=−0.043 / ic_vp=0.048（量级一致，均在 ±0.06 内）。

## 3. 结论（gate 未过，P3 不值得做）

- **三类特征 IC 全部接近 0**（最大 0.020，OBV 还为负）。在 1h / 现货价格序列这个频率与数据源下，
  **无论是量价结构还是横截面强弱，都几乎预测不了"做多能否止盈"**。
- 这与 P1 的统计判定完全自洽：当前框架**根本没有可榨取的方向性 alpha**，
  不是标签（P2 已修对）、不是特征数量（P3 探针证明补上也无效）、不是参数（P0 前已验证）。
- 按路线图 P1 gate 的指定动作：**正确决策是换频率或换数据源，而不是继续在 1h 价格序列上堆特征/调参。**

## 4. 替代路径（真正可能提高收益率的方向）

既然 1h 现货序列无信息量，剩下能撬动收益率的杠杆只有：

1. **换频率**（最高优先级验证）：
   - 更高频（15m）：捕捉微观结构/短期反转，但先确认数据宽度（记忆提示 1m 仅 91 天，15m 可能也窄）。
   - 更低频（4h/1d）：趋势更干净、噪声更低，可能让动量类信号 IC 转正。
   - 用 `probe_cross_section.py` 改 `--momentum-bars` + 另写频率版探针即可低成本验证。
2. **换数据源/另类特征**（真正的信息增量来源）：
   - 订单流（买卖压力、大单净流入）、资金费率期限结构、链上（交易所净流量、稳定币供给）。
   - 这些是"量价/横截面"之外的独立信息源，才可能打破 IC≈0。
3. **P5 降成本/降换手**（当前最现实的净收益改善）：
   - 信号接近随机时，少交易 = 少交手续费。成本吸收率已升到 0.8~2.5，
     降换手（更长持有、提高 `min_score`、冷却）能直接把"略亏"变成"少亏"，
     是框架内唯一不依赖新 alpha 的改善路径。

## 5. 给后续的决定性建议

**停止在 1h 现货价格序列上的特征/标签/参数优化**（P2/P3 已证明边际≈0）。
下一步只做两件事之一，且都先以小探针验证 IC 再投入：
- (A) 换频率探针（15m / 4h / 1d 的动量 IC 是否转正）；
- (B) 引入一类另类数据源（订单流或资金费率结构）重测 IC。
