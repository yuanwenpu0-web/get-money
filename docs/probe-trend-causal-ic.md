# 趋势方向与强度因果 IC 探针

## 假设与结论

根据用户明确要求，复检历史 H2 中已证伪的价格序列路线；这不是新增信息源。固定假设为过去 24 小时动量、12/48 小时 EMA 差或 24 小时趋势效率与未来 24 小时收益相关，跨币平均 Spearman IC 绝对值大于 0.02、同号币种比例不低于 60%。负值表示反转关联，而非趋势延续。

**2026-11-10 复核更正：此前将一次负对照 p=0.008 直接认作校准失效，统计逻辑错误。** 单次 5% 检验本可误报；原值和原判定保留在 JSON `calibration` 中作为历史记录，不再作为现行判据。独立 2,000 次模拟满足本次事先固定的误报容忍条件；4h EMA 差训练、验证两段达到 IC 门槛且同向，具备进入离线交易评估的条件。验证段已用于探针，不再是全新确认样本；未启用策略或修改生产绑定。探针本身的交易收益 verdict 仍为 `insufficient`，不产生每笔收益 95% CI 或随机基线；后续交易级评估的 CI 与多种子随机基线见 `docs/trend-ema-offline-eval.md`。

## 数据边界与方法

来源为本机 PostgreSQL `klines`，数据库连接只读。原报告预留测试段起点固定为 **2026-10-02 12:00 UTC**，所有查询均使用 `open_time < 该时点`；原窗口终点 2026-10-25 仅为记录，不查询测试段。为扩大历史覆盖，本轮使用 2026-01-01 至 2026-08-01 为训练段、2026-08-01 至 2026-10-02 12:00 为验证段；训练及验证仅为研究用途。本轮窗口和划分不同于旧报告，旧结果不能直接相减比较。

固定币池 BTCUSDT、ETHUSDT、BNBUSDT、XRPUSDT、SOLUSDT、ADAUSDT、DOGEUSDT、AVAXUSDT、LINKUSDT、DOTUSDT、LTCUSDT、BCHUSDT；15m、1h、4h 原始数据库记录来源与覆盖在 JSON 中逐项列明，不假定 4h 是交易所原生数据。每币每周期每段要求 open/close 双字段覆盖至少 90%，低于则该段跳过。实际 15m 训练 11 币、验证 4 币；1h 和 4h 各训练 11 币、验证 12 币。BNBUSDT 15m 两段均无覆盖；其余 15m 验证被跳过的币为 ADAUSDT、DOGEUSDT、AVAXUSDT、LINKUSDT、DOTUSDT、LTCUSDT、BCHUSDT；BNBUSDT 1h/4h 训练覆盖约 54%，被剔除。不同段和周期币池不一致，不能直接归因于周期。

特征仅使用 t 收盘及之前数据，标签为 t+1 开盘至 24 小时后开盘的毛收益；跨分段标签删除，缺口不填零，均线按缺口重置。每 24 小时固定相位抽取一次非重叠标签，先逐币算秩相关再等权平均；相邻样本、同币特征及跨币行情仍可能相关，不能视作相互独立。固定单一采样相位可能影响结果，未覆盖所有相位。基准区间涨跌逐币保存在 JSON 的 `baseline` 中。

成本仅作未来评估口径记录：名义本金单边 fee_rate 0.0004、slippage 0.0002，往返近似 0.12%；IC 使用毛收益，未计算交易净收益。未模拟资金费率、盘口深度、冲击或强平。

## 独立因果检查与统计校准

原始记录为 35 组通过、0 组失败、1 组无数据未检验；原检查未记录截断前的非空特征数，因此不能排除部分空比较。离线交易评估额外检查了 4h EMA 差的 12 个币：每币截断前均有非空值（226 至 812 个），截断及未来扰动比较均通过。该检查针对特征计算，不构成对所有成交、标签时序的形式化证明。查询本身硬编码截止于原测试段起点，标签跨段过滤按退出时点执行。

使用独立生成的自相关 AR(1) 序列构造正、弱、零关联对照，并对标签作至少两个前瞻跨度的循环位移，建立保留序列内部自相关的近似零分布。固定种子 20261110，正对照 IC 0.7566、p=0.001；弱对照 IC 0.0746、p=0.102；负对照 IC -0.1241、p=0.008，错误拒绝零假设。100 次独立零假设模拟中 7 次 p≤0.05，经验拒绝率 7%；这是有限样本诊断，不证明真实行情满足平稳性。弱对照按注入强度衰减，并非实证交易信号；以上 p 值只评估合成校准，不是市场结果的显著性检验。

复核：原 7/100 的 Clopper–Pearson 95% 区间为 [2.86%, 13.89%]，对 5% 的双侧精确二项检验 p=0.352；样本量不足以精确限定误报率。另预定独立种子 20261111、2,000 次 AR(1)=0.9、长度 1,200、每次 199 个循环位移，不挑种子：108 次误报，5.40%，双侧 95% 精确区间 [4.45%, 6.48%]，对 5% 双侧检验 p=0.411。预设单侧 95% 上限须低于 10%，实际 6.31%，该合成场景满足容忍条件。未拒绝 5% 不证明真实误报率恰为 5%；10% 是本次预先明确的容忍边界，不是历史规定的显著性水平。全部独立模拟 p 值及旧结果均留在 JSON。正对照显著，弱对照相关性衰减；单次负对照显著属于仍需披露的观测。

循环位移依赖近似平稳和环接假设；上述校准只覆盖指定的合成 AR(1) 场景，不证明市场状态切换或异方差下校准有效。探针本身未计算市场 p 值或 FDR，也没有 3/4 时间段稳定性检验。测试段仍预留，结果不能证明净收益为正或推翻历史 H2 止损线。

## 复现与缺陷

在仓库根目录运行 `./.venv/Scripts/python.exe backend/scripts/trend_ic_probe.py --review` 可复现独立模拟并更新复核字段；脚本无参数运行现已禁止，防止覆盖原始结果。数据库查询上限固定为测试段起点。数据如发生历史修订，读数可能变化。本轮脚本运行成功；人工合成序列的因果性、退化列及测试边界断言通过；报告预检为 0 FAIL、1 WARN（未新建策略，因此无 default_enabled 字段）。全量 `pytest backend/tests -q` 运行进度到 100% 时显示 3 个失败，随后临时目录批量删除被环境安全保护拦截，未输出失败详情，不能宣称全量测试通过。计划任务 `QuantDesk-GetMoney` 查询时为 Ready、未运行；本轮只修改离线探针，未启动该任务。原先校准用未来收益自身作正对照、白噪声作单次负对照，不能检测标签对齐或自相关造成的假阳性；原 13.5 天验证段过短。原单次负对照显著及此前误判均保留记录；复核后不能仅凭该单次结果否定量具。新模拟初次运行在保存时遇到 numpy bool JSON 序列化错误，修正类型后使用相同种子和方案完整重跑，结果未因观察模拟结果而调整。
