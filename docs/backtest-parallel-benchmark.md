- 每配置跑 3 轮取**中位数**并保留全部样本——单次采样波动可达 ±30%（负载、PG 缓存、spawn 冷启动），不可作为结论。

## 结论

- 结果一致性：通过（各配置收益完全相同）。
- **线程只应用于数据提取**：`build_dataset` 有大量 DB 往返，能重叠 IO；`simulate` 是逐 bar 纯 Python 循环，被 GIL 锁死，线程零收益。
- **进程池必须按档复用、只建一次**：Windows spawn 开销很大，每档每轮新建池会比串行更慢。
- 建议：日常跑 `tier_backtest.py` 时加 `--workers 8 --processes 8`。
- 本基准只测速度，不做任何收益结论。
