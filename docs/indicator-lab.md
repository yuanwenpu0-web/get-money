# 指标信号检测与优化实验

> 生成时间 2026-11-01 01:23:50；配置哈希 `947c4c0be49be947`；随机种子 20261101。本文件与同名 json 由同一次运行写出，数值不得手工修改。

## 0. 复现

```bash
.venv\Scripts\python.exe backend/scripts/indicator_lab.py --interval 1h --days 400 --limit 40 --top 8 --draws 60 --seed 20261101
.venv\Scripts\python.exe -m pytest backend/tests/test_indicator_lab.py -q
```

换周期只改 `--interval`（15m / 1h / 4h / 1d 均支持，超时按 bar 数计）；换股票池改 `--limit`，指标集合改 `--families`。所有随机性来自 `--seed`，同参数重跑数值完全一致。

## 1. 实验口径

- 数据：1h **native** 直查，40 个币，2025-09-26 18:00 → 2026-10-26 12:00，共 379000 根 bar
- 出场：统一 `rsi50_cross`（RSI14 Wilder 穿越 50，下一根开盘平仓），超时兜底 240 根，样本末尾按收盘平仓
- 入场：指标信号在 bar t 收盘确认，t+1 开盘成交；单币同时最多一仓，不加仓
- 方向：多空对称（两个方向都开仓）
- 资金：每笔固定 10.0 名义本金；本金基数 = 名义本金 × 最大并发持仓数
- 成本：手续费 0.040%/边 + 滑点 0.020%/边，往返 0.120%
- 切分：训练集 70% / 样本外 30%，切点 2026-06-30 01:48；跨越切点的持仓两边都剔除（purge）
- 搜索规模：单指标 111 组参数 + 组合 57 组，合计 168 次检验

## 2. 结论摘要

- 训练集最优单指标：**rsi_reversal(high=75,low=25,n=14)**，训练盈亏 72.438，样本外 -63.175，判定 `likely_noise`
- 训练集最优组合：**rsi_reversal(high=75,low=25,n=14) OR volume_break(k=3.0,n=20)**，训练盈亏 79.116，样本外 -50.677，判定 `likely_noise`
- 通过全部关卡（q<0.10 且样本外为正）的候选：**0 / 168**
- 训练集为正 4 个，样本外为正 69 个，两者同时为正 0 个（样本外按盈亏排序前 5：`adx_di_cross(adx_min=20,n=14)`、`supertrend_flip(mult=3.0,n=10)`、`supertrend_flip(mult=3.0,n=17)`、`ema_cross(fast=20,slow=72)`、`ema_cross(fast=17,slow=72)`；仅作诊断，不用于选择）
- 基准（同口径 10.0 名义本金/币，全期）：始终做多 -103.821，始终做空 -350.798，买入持有 -23.919
- 结构提示：买入持有训练期 -221.413、样本外 506.760，两段市场方向相反；训练期为正的候选只有 4 个而样本外为正的有 69 个，说明结论对市场状态高度敏感，不能跨 regime 外推

## 10. 过拟合控制与可复现

- 搜索空间预登记：参数区间与步长只在 lab_grid.GRID 定义，运行时写入配置快照并计算 sha256
- 时间切分 70%/30%，跨越切点的持仓两边剔除（purge）
- 候选排序只看训练集；样本外仅作判定，不参与任何选择
- 单指标与组合合并做 BH-FDR（组合来自训练集排名，已消耗自由度，必须计入校正）
- 锚定式滚动验证 3 折：每折用历史段选参，在紧随的验证段判定
- 随机基线：同频率随机入场 60 次，固定种子 20261101
- 全部随机性来自 numpy default_rng(seed)，无系统时间依赖；配置哈希可复核一次运行

## 11. 限制

- 单一 1h 周期、约 13 个月窗口，跨不过完整牛熊，结论只在样本期内成立
- native 1h 直查与 1m 聚合口径的差异未在本轮复核，两者不可混用
- 固定 10 名义本金、无杠杆、未计永续资金费（现货口径），容量与冲击成本未估计
- 单币同时一仓，未处理组合层面的资金竞争与相关性
- 多空规则对称，未做方向择向，因此不含「只做多」这类有效子集
- rsi50 出场与逆势入场存在结构性冲突：RSI 低于 50 的多头会被立刻平掉
- FDR 假设检验独立，指标高度相关时 q 值偏保守，只能当筛子不能当定论
