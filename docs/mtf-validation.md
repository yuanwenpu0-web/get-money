## 4. 采纳门禁结论

- mtf 正窗口 5/7 vs trend 3/7（窗口数增加=True）；mtf 收益均值 0.28% vs trend -0.16%（更高=True）
- 结论：建议启用 mtf_resonance（在 trend_follow 基础上叠加多周期共振过滤）。
- 说明：'trend_follow baseline' 此处取 trend_follow 策略的 as-configured 指标（与 mtf 同为 optimize=True 样本外），为 apples-to-apples 比较；mtf 的共振门控是策略定义的一部分，对两者公平施加。
- 机制解读（诚实口径）：mtf 的改善主要来自把 trend_follow 的两个灾难性回撤窗口（#5 -2.21%→+0.71%、#6 -3.03%→+0.14%）转为小赚/持平，且这些窗口回撤从 ~3-4.5% 压缩到 ~0.5%。即 mtf 首要是**风险/假信号过滤器**，而非收益增强器；它在强趋势窗口（#0）反而放弃了部分上行（1.73% vs 2.94%）。
- 局限与风险：① edge 量级很小（窗口均值 +0.28% vs -0.16%），且集中于迭代6已标注的'近期有利 regime'窗口；② mtf 自身有失败窗口（#3：-1.91%、夏普 -8.48、仅 16.67% 币正收益，劣于 trend 同窗 -0.62%），并非全时段更优；③ 参数用默认 adx_filter=22/htf_adx_filter=20，未针对本数据调参（无过拟合），但也不代表最优点；④ 探索性单窗口对更广宇宙无 edge 证据。
- 部署建议：若采纳，mtf_resonance 作为 trend_follow 的**互补/替代过滤**启用，而非据此放大仓位；保留 maker 费率 + 流动性 $30M 过滤 + 现有黑名单；接入季度 walk-forward 跟踪正窗口占比是否回升；实盘容量受单币种单仓位与保证金约束，回测上界高于实盘可用容量。
- 若不采纳：保留现有 trend_follow，mtf_resonance 作为实验策略保持注册但默认不启用。
