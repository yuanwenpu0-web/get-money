# 订单流净买入策略：实现、回测与参数寻优（结论：无 edge，不启用）

> 需求：用「净买入量」指标建一个策略，回测并探寻最佳参数。
> 本文是本轮完整交付记录：数据口径 → IC 探针 → 分组探针 → 策略实现 → 回测 → 参数寻优 → 出场诊断。
> **最终判定：该指标在扣费后无正 edge，任何参数组合都不可能盈利；策略 `default_enabled=False`，不接入实盘。**

## 1. 指标口径（先说清「净买入量」是什么）

| 名称 | 计算 | 数据性质 | 在哪个模块 |
|---|---|---|---|
| 净主动买入量 | `2 × taker_buy_volume − volume`，等价「主动买 − 主动卖」 | **交易所真实**周期汇总 | 本轮新增 |
| 净买入不平衡 | `sum(净主动买入量, n) ÷ sum(volume, n)`，取值 [−1, 1] | 由真实字段派生 | `fi_ratio` |
| 估算 delta / CVD | 按收盘在高低区间的位置给整根成交量赋号 | **估算**，非真实主动成交 | `features/absorption.py`、`catalog_indicators/cvd_bias.py` |

两者**不是同一口径**，不能互相验证。本轮全程只用真实字段。

数据覆盖（本轮实测）：

- `klines` 1m 共 4,226 万行，其中带 `taker_buy_volume` 2,776 万行（65.7%）。
- 2025-04 起 16–19 个主流币 **100% 覆盖**；2026-07 后扩到 535 币但覆盖率降到 10–38%。
- BTCUSDT 起止：2023-11-02 → 2026-11-03。
- 因此回测窗口定在 **360 天**（16 币全程完整），避免「部分缺失币」把结果带偏。

## 2. 第一层探针：线性 IC（未过门槛）

`scripts/probe_flow_imbalance.py`，400 天 / 19 币 / 15m 完整桶（要求 15 根分钟连续）。

特征 `fi_n` 对不同未来收益的逐币 Pearson IC 取跨币均值，**最好的一组只有 ±0.008**：

| 特征 | 目标 | IC 均值 | 同号比例 | 判定 |
|---|---|---:|---:|---|
| fiz_16 | fwd_16 | +0.0079 | 74% | 远低于 0.02 门槛 |
| fi_8 | fwd_16 | +0.0075 | 68% | 同上 |
| fi_1 | fwd_1 | −0.0061 | 79% | Spearman −0.028（短期反转，极弱） |

按项目铁律（|IC| > 0.02 才投入特征工作），**线性层面已证伪**。
报告：`docs/probe-flow-imbalance.md`。

## 3. 第二层探针：分组/极端值（给出「唯一可能的形态」）

线性 IC 会低估「只有尾部才有信息」的信号，所以补做分位分组。
`scripts/probe_flow_quantile.py`，19 币，分 10 桶 + 尾部 5%/1% 检验。

关键发现（360 天前后一致）：

- **只有做多侧有方向性**：高不平衡做多，超额随持仓周期单调上升；做空侧无 edge。
- 5% 尾部：`fi_48 → fwd_32` 做多超额 +0.117%，扣 0.12% 双边成本后 ≈ −0.006%。
- 1% 尾部：`fi_96 → fwd_64` 做多超额 +0.177%，扣费后 +0.050%（**但这是全样本分位的上限估计，含未来信息**）。

这决定了策略形态：**只做多 + 极端分位入场 + 长持有**，而不是连续打分择时。
报告：`docs/probe-flow-quantile.md`。

## 4. 策略实现

`backend/app/strategy/specs/flow_imbalance_long.py`（注册码 `flow_imbalance_long`）。

| 环节 | 做法 |
|---|---|
| 不平衡 | `fi_ratio = sum(2×主动买 − 总量, flow_window) / sum(总量)` |
| 入场 | `fi_ratio > rolling(quantile_window).quantile(entry_quantile)` 且 `fi_ratio > 0` |
| 分位因果性 | 阈值一律 `shift(1)` 后滚动，**只用已收盘 bar**，消除探针的全样本前视 |
| 缺失语义 | 任一分钟缺主动买入量 → 该 bar `fi_ratio = NaN`，整根作废；**绝不当 0** |
| 出场 | ATR 止损 `sl_atr_mult`、`target_r` 倍目标、`max_hold_bars` 时间止损、不平衡跌破中位软出场 |
| 方向 | 恒定只做多（探针证明做空侧无 edge） |
| 评分 | 阈值→历史上沿映射到 0.6–1.0，供仓位分层 |
| 启用状态 | `default_enabled=False` |

顺带补齐了数据层：`MarketDataService._candle_query` 现在按分钟 `sum(taker_buy_volume)`，
**任一分钟缺失则该桶为 NULL**（不能用 0 冒充，否则不平衡被系统性拉负）。常规 `load_frame()`
从此能直接拿到这两个字段——此前只有离线研究脚本能读。

测试：`backend/tests/test_flow_imbalance_strategy.py`（10 项，含因果性、缺失语义、聚合求和）。
全量回归 1536 passed；4 项失败经 `git stash` 复核为**改动前既有**（`dispatch.halt_status` 缺失等），与本轮无关。

## 5. 回测与参数寻优

`scripts/backtest_flow_imbalance.py`：16 币 / 360 天 / 15m，70% 训练 + 15% 验证 + 15% 测试，
验证集选参（108 组网格，含持有上限），测试集只评估一次；成本 0.04% 手续费 + 0.02% 滑点（双边 0.12%）。

### 测试集结果

| 指标 | 中位数 | 均值 |
|---|---:|---:|
| 总收益 | −1.31% | −2.06% |
| 最大回撤 | −2.85% | −3.60% |
| 胜率 | 52.3% | 49.3% |
| 成交笔数 | 33 | 33 |
| 单笔平均 | −0.55% | −0.54% |

- 16 币中仅 4 币为正（DOGE / LINK / NEAR / APT，均在 +0.5%~+1.8%，量级接近噪声）。
- **11/16 币的每笔期望 95% CI 跨 0**（inconclusive），3/16 高于随机基线 95 分位。
- 平均跑输随机方向基线（随机均值 −1.50% vs 策略 −2.06%），说明方向判断没有信息量。

### 参数寻优：没有任何组合能覆盖成本

独立做了一遍「窗口 × 分位 × 持有期」全扫描（8 币，因果滚动分位，扣费前/后并列）：

| flow_window | entry_quantile | 持有根数 | 毛收益 | 扣费后 | 成本后为正的币 |
|---:|---:|---:|---:|---:|---:|
| 48 | 0.95 | 128 | **+0.1156%** | −0.0044% | 2/8 |
| 48 | 0.98 | 128 | +0.1127% | −0.0073% | 3/8 |
| 96 | 0.90 | 128 | +0.1025% | −0.0175% | 4/8 |
| 48 | 0.95 | 64 | +0.0680% | −0.0520% | 3/8 |
| 48 | 0.95 | 16 | +0.0137% | −0.1063% | 1/8 |

**最优组合（48 / 0.95 / 128 根）的毛收益 +0.1156%，而双边成本 0.12%——刚好差一点点，扣费后为负。**
短持有期更差（成本摊不开），这是结构性结论，不是调参问题。

### 出场诊断：不是止损在毁灭价值

`scripts/diagnose_flow_exit.py` 把「信号是否有效」和「出场规则」分开：

| 口径 | 跨币单笔均值 |
|---|---:|
| 纯持有 8 根（无止损止盈） | −0.111% |
| 纯持有 32 根 | −0.087% |
| 纯持有 64 根 | −0.056% |
| SL=1.0×ATR + 2R 目标 | −0.128% |
| SL=3.0×ATR + 2R 目标 | −0.145% |

纯持有口径**全部为负**，而成本本身就是 −0.12% → 说明**毛收益近似为零**。
止损/目标没有额外毁灭价值，放宽或关闭都救不回来。

方向也没做反：高不平衡做多、低不平衡做空，符号正确，只是幅度不够。

## 6. 结论

1. **净买入量（真实主动买入不平衡）在 15m 上不存在可交易的 edge**。线性 IC ≤ 0.008，尾部效应在扣费后归零。
2. **「最佳参数」是 48 根窗口 / 0.95 分位 / 128 根持有**，毛收益 +0.1156%，扣费后 −0.004%——即**盈亏平衡略偏负**，不具备生产价值。
3. 与项目既有结论一致：现货 OHLCV 价格序列（P0–P10）已证伪，订单流是又一个被验证的「信息增量候选」，同样未通过。
4. 策略保留在注册表但 `default_enabled=False`，不进模拟盘、不进实盘；`spec.grid` 保留供复现。

## 7. 后续若要继续，只有这几条路

- **换成本结构**：当前 0.12% 双边是硬门槛。若能用 maker 挂单（双边 ~0.04%），最优组合的 +0.1156% 毛收益才可能留下 +0.07%——但这是「靠降成本盈利」而非「靠信号盈利」，且对成交假设极敏感。
- **拉长到 1h/4h + 更长持有**：成本占比下降，但样本量和币种覆盖会同时锐减，需先确认数据宽度。
- **换信息维度**：真实逐笔成交流（aggTrades 顺序、大单拆分）、盘口挂撤单。K 线汇总字段已经证明不够。
- **不建议**继续在本指标上调阈值/加过滤器——已扫过窗口 × 分位 × 持有期三维，结论稳定为负。

## 9. 限制

- K 线 `taker_buy_volume` 是**周期汇总**，不含逐笔顺序、盘口挂撤单、订单簿深度。
- 回测未计资金费率（15m–32h 持仓下影响小，但正式决策前应补）。
- 16 币来自本地数据完整性筛选，不是全市场横截面；2026-07 后新增币种因字段缺失被排除。
- 参数寻优在验证集上做、测试集评估一次，但「先扫一遍再报告最优」仍存在多重比较偏差；本结论为负，偏差方向不影响判定。
