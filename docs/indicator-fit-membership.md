## 1. 发现一个真实缺陷：残月标记因 int32 溢出恒为 False

`fit_data.monthly_quote_volume` 内联算应有柱数时用 `.dt.days_in_month`（pandas 3.x 为 int32）乘 `DAY_MS=86400000`。30 天 → 2.59e9 超过 int32 上限，结果翻负（-474 根），于是 `bars < 0.7 × 负数` 恒为 False，**partial 全库失效**。

后果：窗口首尾只盖到十几天的残月从未被剔除，直接进入 Q 档的月度成交额中位数，也进入逐月档位与档位稳定率。这与 `assign_fixed_tiers` docstring 声明的口径相反。

- 已修：`month_expected_bars` 先升 int64 再乘；`mark_partial_months` 统一判定。
- 用溢出仍生效的口径复现 A 轮冻结档位：**MATCH**（不变 80、改档 0、掉出 0、新增 0）。

- 只测量成员口径，不产生净收益数字，不改 A 轮统计与标签。
