# Pine Script 源码合集

本目录保存 [casoon/pine-scripts](https://github.com/casoon/pine-scripts) 作者仓库的 100 个 Pine v6 文件，来源固定在提交 [`c7368182c246853f246911831171bc8258bc356a`](https://github.com/casoon/pine-scripts/tree/c7368182c246853f246911831171bc8258bc356a)，获取日期 2026-10-28。

其中 96 个为独立指标：每个指标主目录选取一个当前版本，并额外选取 Vein 套件中另一个独立组件；4 个为独立策略文件。指标和策略可能基于同一套信号逻辑。文件不代表 TradingView 全站排名；作者说明只有部分脚本发布在 TradingView。

[中文目录](中文目录.md) 按条展示原文摘录、中文备注及本地源码链接。`index.json` 中的 `description_zh` 是对应原文摘录的中文翻译，而非全文翻译。

`index.json` 每条的 `path` 保持上游仓库的相对路径；`title` 和 `original_description` 来自对应源文件头部，说明按首段提取并合并换行，可能为英文或德文，并不包含全部功能和限制。`source_url` 指向固定提交中的原文件，`sha256` 是原始文件字节的 SHA-256。源码未经修改，许可证原文见 `LICENSE`。MIT 许可要求在复制或重要部分中保留版权和许可声明。

这些脚本是第三方研究资料，并非本项目已支持或验证过的策略；导入前请检查源码、参数与适用条件。
