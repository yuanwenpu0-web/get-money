# Using the Harmonic Pattern Recognition Indicator

## Basic Usage

1. **Install the Indicator**
   - Copy the entire `harmonic_patterns.pine` script from this repository
   - Open TradingView and paste it into the Pine Editor
   - Save the indicator to your personal scripts
   - Add it to your chart

2. **Reading Pattern Signals**
   - Bullish patterns are marked in green
   - Bearish patterns are marked in red
   - Each pattern shows:
     - Pattern name and quality rating
     - Entry price level
     - Stop-loss level
     - Profit target levels (T1, T2)

3. **Customizing the Indicator**
   - Open indicator settings by clicking on the gear icon
   - Adjust which patterns to detect
   - Modify visual appearance
   - Configure alert settings

## Advanced Settings

### Pattern Selection
Enable or disable specific harmonic patterns:
- Bat Pattern
- Butterfly Pattern
- Crab Pattern 
- Shark Pattern

### Display Options
Customize what information is shown:
- Show/hide pattern labels
- Show/hide prediction zones
- Show/hide price levels
- Show/hide quality ratings

### Alert Configuration
Set up alerts for:
- New pattern detection
- Pattern completion
- Price approaching D point
- Based on pattern quality

### Sensitivity Controls
Adjust how strictly patterns are identified:
- Tolerance setting (default: 0.05 or 5%)
- Pivot sensitivity
- Lookback period
