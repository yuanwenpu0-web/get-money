# 加密货币相关 Pine Script 合集

合集目前收录 **124 个源码文件**，来自作者公开的 GitHub 项目；这不是 TradingView 热门榜。优先收录面向 BTC、加密永续或 24/7 加密市场的项目，也包含作者明确说可用于加密的通用策略，具体见下表。

中文说明为作者说明的翻译或摘译；英文原文、固定提交、源码链接和 SHA-256 见各目录的 index.json。完整原始说明及许可证见各来源目录。作者关于收益、效果的说法未经独立验证。

Eterna 面向 Bybit 永续合约，策略含交易和告警配置；运行前请检查交易品种、参数及通知设置。Capital41 的现货、永续和 OI 输入需要配置，成交量替代值不是真实 OI。
